# QA-Abgleich F-01 · Projektgerüst und Kartentafel

Geprüft auf `feature/F-01-projektgeruest`, Stand nach `32602bc` (Tests rot) und `eb8218f`
(Umsetzung grün).

## Befund 1: Content-Security-Policy fehlte (NFR-24)

**Beobachtung.** `features/F-01-projektgeruest.md` listet in den Fachregeln „Content-Security-
Policy ohne `unsafe-inline` für Skripte" mit Quelle NFR-24. Weder `svelte.config.js` noch
`src/app.html` noch der gebaute Output (`build/index.html`) enthielten eine CSP. Der
adapter-static-Build fügt zudem ein Inline-`<script>` für den Hydration-Bootstrap ein — ohne
CSP-Konfiguration hätte eine spätere CSP zwingend `unsafe-inline` gebraucht, um dieses Skript
zuzulassen, was der Regel direkt widerspricht.

**Verletzte Quelle.** `features/F-01-projektgeruest.md` (Fachregeln-Tabelle) und PRD NFR-24.

**Behebung.** `svelte.config.js` um `kit.csp = { mode: 'hash', directives: { 'script-src':
['self'] } }` ergänzt. SvelteKit trägt beim (prerendered) Build jetzt automatisch den Hash des
einzigen Inline-Bootstrap-Skripts in ein `<meta http-equiv="content-security-policy">` ein,
ohne `unsafe-inline`. Verifiziert im gebauten `build/index.html`:
`content-security-policy` · `script-src 'self' 'sha256-…'`.

## Befund 2: Kopfband ignorierte die Mobil-Anordnung des Entwurfs unter 768 px

**Beobachtung.** `design/03-seekarte.html` blendet ab `@media (max-width:768px)` den
Untertitel im Kopfband aus (`.title span{display:none}`) und hebt den `margin-left:auto` des
Tafel-Bereichs auf (`.scope{margin-left:0}`). `src/app.css` enthielt keine entsprechende
Media Query. Am laufenden Programm bei 375 px brach „Blatt 1 · Impact / Effort" dadurch auf
zwei Zeilen um, statt wie im Entwurf zu verschwinden — kein horizontales Scrollen und keine
optische Überlappung (Kopfband blieb bei fixer Höhe von 60 px durch `align-items:center`
innerhalb der Grenzen), aber eine abweichende Anordnung gegenüber dem verbindlichen Entwurf.
Bei 834 px und 1440 px (beide > 768 px) war das Kopfband bereits vor der Behebung deckungsgleich
mit dem Entwurf.

**Verletzte Quelle.** `design/03-seekarte.html` (Anordnung des Kopfbands unter 768 px);
mittelbar F-01-AK2 („Kopfband … in der Aufteilung des Entwurfs").

**Behebung.** In `src/app.css` dieselbe Media Query wie im Entwurf ergänzt (auf den in F-01
vorhandenen Umfang beschränkt — `.index`, `.legend`, `.detail` aus dem Entwurf existieren in
diesem Feature noch nicht und wurden bewusst nicht übernommen):

```css
@media (max-width: 768px) {
	.title span {
		display: none;
	}
	.scope {
		margin-left: 0;
	}
}
```

Am laufenden Programm erneut geprüft (375 px): Untertitel jetzt ausgeblendet, kein
horizontales Scrollen, Tafel-Schalter unverändert erreichbar.
